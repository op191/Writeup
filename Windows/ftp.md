**Windows 的 FTP 就是 Windows 系统自带的一个“文件共享服务”**，专门用来让其他人通过**网络**往你的电脑里**上传**或**下载**文件。

你可以把它想象成：你在自己电脑上开了一个**公共网盘（文件夹）**，别人只要知道你的 IP 地址和账号密码，就能往里塞文件或把文件拷走。

---

### 🔧 怎么开启？

它默认是关闭的，在**控制面板** → **启用或关闭 Windows 功能**里，把 **Internet Information Services (IIS)** 下的 **FTP 服务器** 勾上，这个功能就装好了。

---

### 💻 别人怎么连？

别人可以通过这几种方式来连：

- **浏览器**：直接在地址栏输入 `ftp://你的IP地址`，按回车就能看到文件夹内容。
    
- **命令行**：在 Linux 终端或 Windows CMD 里输入 `ftp 你的IP地址`，然后输入账号密码。
    
- **专门软件**：比如 FileZilla 这种 FTP 客户端，界面更友好。
    

---

### 🎯 在渗透测试中，你关心它什么？

- **明文传输（大问题）**：传统的 FTP（端口 21）**账号密码和数据都是明文传输的**，没有加密。如果你在内网里抓到别人的 FTP 数据包，就能直接看到他的密码，这是重要的突破口。
    
- **匿名登录**：很多管理员图省事，会开启“匿名登录”功能。这意味着你**不需要账号密码**就能连上去，可以随意下载或上传文件（甚至上传 Webshell 拿下服务器权限）。
    
- **横向移动的跳板**：如果你拿到了一台机器上的 FTP 账号密码，且密码与其他机器相同，就可以把它作为横向移动的起点。
    

---

### 🧠 值得记住的点

|特性|说明|
|---|---|
|**默认端口**|21（命令通道）、20（数据通道）|
|**安全性**|⚠️ 极差，明文传输，极易被嗅探（抓包看密码）|
|**常见版本**|Windows 自带的 IIS FTP 服务器，或第三方的 FileZilla Server、Serv-U|
|**配置文件**|一般位于 `C:\inetpub\ftproot`（默认根目录），但你扫到开放 21 端口后，要用 `nmap -sV` 看版本再搜漏洞|

---

**一句话总结**：FTP 是 Windows 上一个老旧的“文件传送门”，**方便但极不安全**。渗透中，你扫到 21 端口开放，第一反应就是：**试试匿名登录，或者抓包看密码**。
