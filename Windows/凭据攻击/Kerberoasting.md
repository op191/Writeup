**任何普通域用户都可以向域控请求任意服务的“服务票据”（ST），然后抓下来离线破解服务账户的密码**。

---

### 🔑 攻击流程

| 步骤         | 操作                                                              | 原理                                         |
| ---------- | --------------------------------------------------------------- | ------------------------------------------ |
| **① 请求票据** | 用任意域用户（哪怕没权限），向域控请求某个SPN（服务主体名称，如 `MSSQLSvc/sql.domain.com`）的ST | 域控只要确认用户身份合法，就会返回该服务的ST，**不检查用户是否有权访问该服务** |
| **② 导出票据** | 用 `GetUserSPNs.py`、`Rubeus` 等工具导出ST到本地                          | ST是用**服务账户的NTLM哈希**加密的                     |
| **③ 离线破解** | 用 `hashcat` 在本地跑字典，破解ST                                         | 能解开ST的密码，就是服务账户的明文密码                       |

**获取ST（服务票据）的TGS-REQ请求，本身就需要一个合法的TGT，而TGT必须用密码登录才能拿到。**

---

### 🔑 完整流程对比

| 步骤         | AS-REP Roasting（GetNPUsers.py） | Kerberoasting（GetUserSPNs.py）          |
| ---------- | ------------------------------ | -------------------------------------- |
| **前提**     | 目标用户**未开启预认证**                 | 你手中必须有**一个合法的域用户账号密码**                 |
| **① 初始请求** | 直接发AS-REQ，**不带加密时间戳**          | 先用你的账号密码完成AS-REQ/AS-REP，**拿到一个合法的TGT** |
| **② 中间步骤** | ❌ 跳过                           | 拿着TGT，向DC发起TGS-REQ，**请求某个SPN对应的ST**    |
| **③ 返回内容** | DC直接返回**用目标用户NTLM哈希加密的TGT**    | DC返回**用服务账户NTLM哈希加密的ST**               |
| **④ 破解对象** | 目标用户本身的密码哈希                    | 服务账户的密码哈希                              |
| **是否需要密码** | ❌ **不需要**                      | ✅ **必须有一个合法账号密码**（用于第一步登录拿TGT）         |
