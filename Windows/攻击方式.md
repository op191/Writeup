## 第一阶段：侦察与信息收集

| 中文名          | 英文名                  | 核心工具                                         | 一句话说明                             |
| ------------ | -------------------- | -------------------------------------------- | --------------------------------- |
| LDAP枚举       | LDAP Enumeration     | `ldapsearch`, `enum4linux`, `BloodHound`     | 查询AD数据库，枚举用户/组/计算机/OU/SPN         |
| SMB枚举        | SMB Enumeration      | `enum4linux`, `smbclient`, `crackmapexec`    | 枚举SMB共享、会话、用户列表                   |
| 用户枚举         | User Enumeration     | `kerbrute`, `enum4linux`, `rid-brute`        | 通过Kerberos或SMB RID爆破枚举域内用户名       |
| SPN枚举        | SPN Enumeration      | `ldapsearch`, `GetUserSPNs.py`, `BloodHound` | 枚举所有设置了SPN的服务账户（Kerberoasting的前置） |
| BloodHound采集 | BloodHound Ingestion | `SharpHound`, `BloodHound.py`                | 采集AD数据，导入BloodHound分析最短攻击路径       |

## 第二阶段：初始凭证获取

| 中文名             | 英文名                       | 核心工具                                    | 一句话说明                               |
| --------------- | ------------------------- | --------------------------------------- | ----------------------------------- |
| Kerberoasting   | Kerberoasting             | `GetUserSPNs.py`, `Rubeus`, `hashcat`   | 请求SPN对应的ST票据，离线破解服务账户密码             |
| AS-REP Roasting | AS-REP Roasting           | `GetNPUsers.py`, `Rubeus`               | 攻击未启用预认证的账户，直接请求TGT并离线破解            |
| NTLM中继攻击        | NTLM Relay Attack         | `Responder`, `ntlmrelayx.py`, `Inveigh` | 截获NTLM挑战-响应，中继到其他机器实现登录             |
| LLMNR/NBT-NS投毒  | LLMNR/NBT-NS Poisoning    | `Responder`, `Inveigh`                  | 伪造LLMNR/NBT-NS响应，截获内网用户Hash         |
| 密码喷洒            | Password Spraying         | `crackmapexec`, `hydra`, `kerbrute`     | 用同一个弱密码尝试大量用户（绕过账户锁定）               |
| 暴力破解            | Brute-Force               | `hydra`, `ncrack`, `hashcat`            | 针对单个账户穷举密码（容易触发锁定策略）                |
| 离线密码破解          | Offline Password Cracking | `hashcat`, `john`                       | 拿到NTLM Hash或Kerberos票据后，离线跑字典/掩码/规则 |

## 第三阶段：权限提升与横向移动

| 中文名      | 英文名                   | 核心工具                                     | 一句话说明                            |
| -------- | --------------------- | ---------------------------------------- | -------------------------------- |
| 哈希传递     | Pass-the-Hash (PtH)   | `crackmapexec`, `psexec.py`, `mimikatz`  | 直接用偷来的NTLM Hash认证，无需破解明文密码       |
| 票据传递     | Pass-the-Ticket (PtT) | `mimikatz`, `Rubeus`                     | 直接注入偷来的Kerberos票据（TGT/ST）到当前会话   |
| 黄金票据     | Golden Ticket         | `mimikatz`, `ticketer.py`                | 用krbtgt Hash伪造任意用户的TGT，拿到域控权限    |
| 白银票据     | Silver Ticket         | `mimikatz`                               | 用服务账户Hash伪造访问特定服务的ST（权限受限）       |
| 钻石票据     | Diamond Ticket        | `Rubeus`, `mimikatz`                     | 在合法TGT基础上修改PAC，提权（比黄金更隐蔽）        |
| SMB纵向移动  | SMB Lateral Movement  | `psexec`, `wmiexec`, `smbexec`, `atexec` | 用SMB/WMI计划任务在远程机器执行命令            |
| RDP横向移动  | RDP Lateral Movement  | `xfreerdp`, `mstsc`                      | 凭Hash/密码直接RDP登录其他机器（需开启远程桌面）     |
| 哈希传递与RDP | RDP Pass-the-Hash     | `xfreerdp` + `/pth`                      | 用Hash直接RDP（需启用“受限管理”模式）          |
| DCSync攻击 | DCSync Attack         | `mimikatz`, `secretsdump.py`             | 模拟域控同步行为，请求复制所有密码哈希              |
| DCSync后门 | DCSync Backdoor       | `mimikatz`                               | 给普通用户授予Replication权限，持久化DCSync能力 |

| ------------- | ------------------- | -------------------------- | ------------------------------ |
| Skeleton Key  | Skeleton Key        | `mimikatz`                 | 在域控LSASS里注入万能密码（所有用户都能用这个密码登录） |
| 进程注入          | Process Injection   | `mimikatz`, `CobaltStrike` | 将代码注入LSASS等系统进程，实现隐蔽持久化        |

| 持久化服务         | Persistence Service | `sc`, `schtasks`           | 创建计划任务或服务，开机自启反弹shell          |
| AdminSDHolder | AdminSDHolder       | `ldapmodify`, `PowerShell` | 修改受保护对象的ACL，让特定用户获得持久域管权限      |

## 第五阶段：凭证转储

| 中文名         | 英文名               | 核心工具                                     | 一句话说明                                   |
| ----------- | ----------------- | ---------------------------------------- | --------------------------------------- |
| DCSync      | DCSync            | `mimikatz`, `secretsdump.py`             | 通过AD Replication API从域控拉取所有用户的NTLM Hash |
| NTDS.dit转储  | NTDS.dit Dump     | `secretsdump.py`, `vssadmin`, `ntdsutil` | 直接提取域控上的AD数据库文件，离线导出所有Hash              |
| LSASS内存转储   | LSASS Memory Dump | `mimikatz`, `procdump`, `comsvcs.dll`    | 从进程内存中提取登录凭证（明文密码/Hash/票据）              |
| SAM转储       | SAM Dump          | `reg.exe save`, `mimikatz`               | 导出本地SAM文件，提取本地账户的NTLM Hash              |
| LSA Secrets | LSA Secrets       | `mimikatz`                               | 提取注册表中存储的服务账户密码、自动登录密码                  |
