### 单机凭据来源

- **SAM**：本地用户密码哈希。路径 `C:\Windows\System32\config\SAM`。存所有本地账户的 NTLM 哈希。dump 它需要**本地管理员或 SYSTEM** 权限。

- **SYSTEM**：注册表 hive，存 **SAM 解密所需的密钥**。路径 `C:\Windows\System32\config\SYSTEM`。**单独拿 SAM 没用，必须配合 SYSTEM 才能解密出哈希。**

- **LSA Secrets**：本地安全机构机密。路径 `C:\Windows\System32\config\SECURITY`。存**服务账户密码、自动登录凭据、VPN 凭据**等。dump 它需要 SYSTEM 权限。

- **LSASS 内存**：运行时凭据。进程 `lsass.exe` 的内存里，存着**当前登录用户的明文密码或哈希**。dump 它需要管理员或 SYSTEM 权限，是**最直接的凭据来源**。

- **DPAPI**：数据保护 API。存**浏览器密码、WiFi 密码、凭据管理器**里的加密数据。解密需要用户密码或 SYSTEM 权限。

- **注册表**：自动登录凭据。路径 `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon`。存 `DefaultUserName` 和 `DefaultPassword`，如果有的话。

- **凭据文件**：配置文件、脚本、`unattend.xml`、`web.config` 等。里面可能有明文密码或加密凭据。

### 📝 对比表

| 来源              | 存什么            | 需要什么权限       | 工具                           |
| --------------- | -------------- | ------------ | ---------------------------- |
| **SAM**         | 本地用户哈希         | 管理员/SYSTEM   | `nxc --sam`、`secretsdump.py` |
| **SYSTEM**      | SAM 解密密钥       | 管理员/SYSTEM   | `nxc --sam` 会自动一起拿           |
| **LSA Secrets** | 服务账户密码、自动登录    | SYSTEM       | `nxc --lsa`、`secretsdump.py` |
| **LSASS 内存**    | 当前登录用户明文/哈希    | 管理员/SYSTEM   | `mimikatz`、`procdump`        |
| **DPAPI**       | 浏览器/WiFi/凭据管理器 | 用户密码或 SYSTEM | `mimikatz`、`nxc --dpapi`     |
| **注册表**         | 自动登录凭据         | 读注册表权限       | `reg query`                  |
| **凭据文件**        | 明文/加密密码        | 读文件权限        | 手动翻、`grep`                   |
