分为 3 类

纯压缩：即把文件用算法缩小文件大小，只能处理单个文件，所以不能处理目录，代表工具：gzip, bzip,xz

纯打包： 把多个文件合成一个文件，把一个目录中的所有文件合成一个文件，因为文件只能单个上传，不能直接上传文件夹，工具：tar

压缩＋打包：先用tar将多个文件打包，再用压缩工具缩小体积；

tar命令：

参数-c 创建新的打包文件（create） -x 解包(extract提取) -f 指定要操作的包 （filename） -v 显示详细过程（verbose看进度用的)  -t 查看包内文件，不会解包

查看包内文件：

tar -tf  包名

打包一个目录的所有文件：

tar -cvf  生成包名.tar 需要打包目录的路径

打包多个文件：
tar -cvf 生成包名.tar  打包文件1 打包文件2 打包文件3 .....

解包：

tar -xvf  包名.tar
