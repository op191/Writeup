**`grep -rnwi "关键词" /`**

口诀：

> **grep 递归 (r) 显示行号 (n) 全词 (w) 不区分大小写 (i) 关键词 搜根目录**

你给的完整命令可以简化成这个核心骨架：

```
grep -rnwi "PASSWORD" /
```

后面的 `--color` 和 `2>/dev/null` 是 “美化 + 降噪” 的附加项，先记骨架。

------

## 二、拆解每个参数的「联想记忆」

| 参数         | 全称 / 含义               | 记忆联想                                                  |
| :----------- | :------------------------ | :-------------------------------------------------------- |
| `-r`         | recursive（递归）         | **r = 绕着搜**，从根目录往下绕着所有文件夹搜              |
| `-n`         | line number（行号）       | **n = 第几行**，搜出来直接告诉你在文件的第几行            |
| `-w`         | word（完整单词）          | **w = 完整词**，只匹配完整的 PASSWORD，避免误搜到无关词   |
| `-i`         | ignore case（忽略大小写） | **i = 不管大小写**，PASSWORD、password、Password 都能搜到 |
| `"PASSWORD"` | 搜索关键词                | 你要找的东西，这里就是 “密码”                             |
| `/`          | 根目录                    | **/ = 全盘搜**，从系统最顶层开始搜所有文件                |

附加项（不用死记，理解就行）：

- `--color=always`：**给结果上色高亮**，方便一眼看到密码
- `2>/dev/null`：**把报错丢黑洞**，过滤掉 “权限不足” 的垃圾信息

------

## 三、场景联想（结合提权实战，记得更牢）

把它和你的渗透目标绑定起来：

> 我现在是个低权限用户，想在整个系统里找明文密码 → 我要：
>
> 
>
> 1. **递归搜**所有文件（`-r`）
> 2. 告诉我密码在文件的哪一行（`-n`）
> 3. 只搜完整的密码关键词，别乱匹配（`-w`）
> 4. 不管大写小写都能搜到（`-i`）
> 5. 从根目录全盘搜（`/`）
> 6. 结果高亮，报错屏蔽（附加项）

一句话场景版：

**全盘递归搜密码，不区分大小写，只匹配完整词，显示行号，高亮结果，屏蔽报错。**

## 四、

```
# 搜密码
grep -rnwi "password" / 2>/dev/null

# 搜密钥/令牌
grep -rnwi "secret\|token" / 2>/dev/null
```
