| 类别              | 典型场景                                               | 核心思路                                   |
| ----------------- | ------------------------------------------------------ | ------------------------------------------ |
| **sudo 权限滥用** | sudo -l` 看到 `(root) NOPASSWD: 某个命令`              | 用被授权的命令，以 root 身份执行 shell     |
| **SUID 程序提权** | `find / -perm -u+s -type f 2>/dev/null` 找到 SUID 程序 | 利用程序的漏洞或功能，劫持执行 shell       |
| **环境变量劫持**  | 脚本里用相对路径调用命令（如 `tar`、`find`）           | 伪造同名恶意程序，通过修改 `PATH` 优先执行 |
| **定时任务漏洞**  | `crontab -l` 或 `/etc/crontab` 里有可写的脚本          | 篡改定时任务脚本，让它执行反弹 shell       |
| **内核漏洞**      | 内核版本老旧（如 `uname -r` 看到 2.x/3.x）             | 利用 CVE 提权（如 Dirty Cow）              |
