## Docker 基础命令大全

按使用频率和场景分类，帮你快速上手 👇

---

### 1️⃣ 镜像管理（Images）

|命令|说明|例子|
|---|---|---|
|`docker images`|列出本地所有镜像||
|`docker pull <镜像名>`|从仓库拉取镜像|`docker pull nginx`|
|`docker search <关键词>`|在仓库搜索镜像|`docker search ubuntu`|
|`docker rmi <镜像ID>`|删除镜像|`docker rmi nginx`|
|`docker build -t <名称> .`|从 Dockerfile 构建镜像|`docker build -t myapp .`|

---

### 2️⃣ 容器生命周期（最常用）

|命令|说明|例子|
|---|---|---|
|`docker run <镜像>`|创建并启动容器|`docker run nginx`|
|`docker run -d <镜像>`|**后台运行**（detach）|`docker run -d nginx`|
|`docker run -it <镜像>`|**交互式运行**（进入终端）|`docker run -it ubuntu bash`|
|`docker run -p 8080:80`|**端口映射**（宿主机:容器）|`docker run -p 8080:80 nginx`|
|`docker run --name <名称>`|给容器起名字|`docker run --name web nginx`|
|`docker ps`|查看**运行中**的容器||
|`docker ps -a`|查看**所有**容器（包括已停止）||
|`docker start <容器>`|启动已停止的容器|`docker start web`|
|`docker stop <容器>`|停止运行中的容器|`docker stop web`|
|`docker restart <容器>`|重启容器|`docker restart web`|
|`docker rm <容器>`|删除容器（需先停止）|`docker rm web`|

---

### 3️⃣ 常用组合拳（run 参数详解）

bash

# 最常用的 Web 服务启动方式
docker run -d \
  --name mynginx \
  -p 8080:80 \
  -v /host/data:/app/data \
  --restart=always \
  nginx

|参数|含义|
|---|---|
|`-d`|后台运行，不占用终端|
|`-p 宿主机端口:容器端口`|端口映射，外部访问宿主机端口就能到容器|
|`-v 宿主机目录:容器目录`|**挂载卷**，让容器数据持久化在宿主机|
|`--restart=always`|容器挂了自动重启|
|`--network <网络名>`|指定网络模式（bridge/host/macvlan）|
|`-e 环境变量名=值`|设置环境变量（如数据库密码）|
|`--rm`|容器停止后自动删除（适合临时测试）|

### 4️⃣ 进入容器内部（调试用）

bash

# 进入运行中容器的 shell（最常用）
docker exec -it <容器名> /bin/bash
# 例子：进入 nginx 容器
docker exec -it mynginx /bin/bash
# 如果容器没有 bash，用 sh
docker exec -it mynginx /bin/sh

`-it` = **交互式终端**，进去后就像 SSH 到一台小 Linux 里。

### 5️⃣ 查看日志和状态

|命令|说明|
|---|---|
|`docker logs <容器>`|查看容器日志（输出）|
|`docker logs -f <容器>`|**实时跟踪**日志（类似 `tail -f`）|
|`docker logs --tail 100 <容器>`|只看最后100行|
|`docker inspect <容器>`|查看容器详细配置（IP、挂载、环境变量等）|
|`docker stats`|实时查看容器资源占用（CPU/内存）|
|`docker port <容器>`|查看容器的端口映射情况|

---

### 6️⃣ 网络管理（跟你的问题相关）

|命令|说明|
|---|---|
|`docker network ls`|列出所有网络|
|`docker network inspect <网络名>`|查看网络详情（看有哪些容器在里面）|
|`docker network create <名称>`|创建自定义网络|
|`docker network create --subnet=10.46.13.0/24 mynet`|创建指定网段的网络|
|`docker network connect <网络> <容器>`|把容器加入网络|
|`docker network disconnect <网络> <容器>`|把容器移出网络|

---

### 7️⃣ 清理（释放磁盘空间）

bash

# 停止所有运行中的容器
docker stop $(docker ps -q)
# 删除所有已停止的容器
docker container prune
# 删除所有未使用的镜像
docker image prune
# 删除所有未使用的网络
docker network prune
# 一键清理所有（容器、镜像、网络、构建缓存）
docker system prune -a

### 8️⃣ 实战场景速查

|场景|命令|
|---|---|
|**跑一个 Nginx 并映射端口**|`docker run -d -p 8080:80 --name web nginx`|
|**跑一个 Ubuntu 并进入终端**|`docker run -it --name test ubuntu bash`|
|**跑一个 MySQL 并设置密码**|`docker run -d -e MYSQL_ROOT_PASSWORD=123456 mysql`|
|**把容器数据存到宿主机**|`docker run -d -v /my/data:/app/data myapp`|
|**看容器 IP 地址**|`docker inspect <容器> \| grep IPAddress`|
|**拷贝文件到容器**|`docker cp /host/file.txt 容器名:/tmp/`|
|**保存镜像为文件**|`docker save -o myimage.tar myimage`|
|**从文件加载镜像**|`docker load -i myimage.tar`|

### 9️⃣ 常见错误处理

|问题|解决|
|---|---|
|`port is already allocated`|端口被占用，换一个 `-p` 端口|
|`container already exists`|同名容器已存在，删掉或用不同名字|
|`no such container`|容器名打错了，用 `docker ps -a` 确认|
|`permission denied`|没加 `sudo`，或者用户不在 docker 组|
