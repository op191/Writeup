一般用来爆破协议

用法：（**目标ip一定要在协议前**）

```
hydra [参数] 目标 服务协议
```

| 记忆锚点 (Memory Key) | 参数      | 英文全称 / 记忆逻辑    | 作用说明                                |
| :-------------------- | :-------- | :--------------------- | :-------------------------------------- |
| **Login (登录)**      | **`-l`**  | **l**ogin              | 单个用户名                              |
|                       | **`-L`**  | **L**ist of logins     | 用户名字典文件                          |
| **Pass (密码)**       | **`-p`**  | **p**assword           | 单个密码                                |
|                       | **`-P`**  | **P**asswords list     | 密码字典文件                            |
| **Combine (组合)**    | **`-C`**  | **C**olon separated    | 批量 `user:pass` 格式文件               |
| **Extra (额外)**      | **`-e`**  | **e**xtra checks       | `n`(空密码) / `s`(同名密码) / `r`(反转) |
| **Threads (线程)**    | **`-t`**  | **t**hreads            | 并发线程数（默认16）                    |
| **Server (服务器)**   | **`-M`**  | **M**ultiple targets   | 批量目标列表文件                        |
| **Port (端口)**       | **`-s`**  | **s**ervice port       | 指定非默认端口                          |
| **Output (输出)**     | **`-o`**  | **o**utput file        | 保存结果到文件                          |
| **Verbose (详细)**    | **`-vV`** | **v**erbose            | 显示详细过程（通常用大V看尝试）         |
| **Stop (停止)**       | **`-f`**  | **f**inish / **f**irst | 找到第一对密码后退出                    |
| **SSL (安全)**        | **`-S`**  | **S**SL                | 连接使用 SSL 加密                       |

例子

```
hydra -L users.txt -P pass.txt -t 64 -f -vV 192.168.1.100 ssh
```
